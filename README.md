## Tech Stack 💻

**Frontend:** React, TypeScript, HTML, CSS, JavaScript
**Animation & 3D:** GSAP, Three.js, React Three Fiber, WebGL, Rapier (physics)
**Tooling:** Vite, ESLint

> ⚠️ **Note on GSAP:** This project uses GSAP's trial plugins in place of the Club GreenSock plugins. Trial plugins cannot be used on a hosted/production site. If you plan to deploy this project, you'll need a GSAP Club membership — see the [official installation docs](https://gsap.com/docs/v3/Installation/) for details.

## Getting Started 🏁

Clone the repository and install dependencies:

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
npm install
```

Run the development server:

```bash
npm run dev
```

The site will be available at `http://localhost:5173`.
